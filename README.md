# CourseCompass

**A Hybrid Information Retrieval and Knowledge-Graph-Based Assistant for Curriculum Exploration and Skill-Gap Analysis**

## About the Project

CourseCompass is an academic information retrieval system designed to help students explore course curricula, understand topic prerequisites, discover learning outcomes, and connect academic topics with relevant career skills.

The project combines traditional keyword-based retrieval, semantic search, hybrid ranking, knowledge graphs, and Retrieval-Augmented Generation (RAG).

## Key Features

- BM25-based keyword retrieval
- Semantic search using sentence embeddings
- Hybrid retrieval using Reciprocal Rank Fusion (RRF)
- Knowledge graph of courses, topics, prerequisites, and skills
- Retrieval-Augmented Generation for grounded answers
- Curriculum-to-skill mapping
- Retrieval evaluation
- Interactive Streamlit application

## Technology Stack

- Python
- PyMuPDF
- Pandas
- BM25
- Sentence Transformers
- FAISS
- NetworkX
- Streamlit
